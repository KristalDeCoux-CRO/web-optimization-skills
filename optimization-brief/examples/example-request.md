# Example request

Paste a request like this after asking Claude for an optimization brief:

> From a chat message: "Our homepage hero takes up most of the screen and almost nobody scrolls past it. Can we test a shorter hero with a smaller image to see if more people reach the product cards below? All visitors, all devices. We care most about scroll depth, but also want to see hero clicks and free trial starts. We'd like it live before the spring campaign on March 3."

The skill classifies it as an A/B test, drafts the hypothesis ("If we shorten the homepage hero, more visitors will reach the product cards, because the current hero fills the first screen and hides the content below it"), flags that sizing data is missing, flags the homepage hero approval rule, and writes the tracking issue, platform brief, test plan and review email.
